## Open before this goes to press

- On-sale date
- Press contact name and email
- ACE box is titled *Air Suction Massager* but the badges read *Deep & Rumbly Vibrations* — decide the correct description
- SMASH box prints *12 Intensities & Patterns*; the spec is *8 modes × 5 intensities*. Press copy uses the spec.
- The three-box group shot is only available at 1280 × 854 (WhatsApp copy) — needs the original if it stays the lead image
